# 效果优先编排与证据复用

这份参考用于复杂原型协作、共享状态或样式改造、跨模块实施、已有验收复用和外部发布。简单局部修改不必读取。

## 证据账本

复用当前计划、子代理派单和验收回执维护证据，不默认创建额外文件，也不为记账单独运行命令。

每个开放风险保留一行，并在原位置更新：

```text
state_key | risk_cell | evidence_method | result | decision/status
```

- `state_key`：复用已有源码或构建版本，并补充路由、视口、测试数据和界面状态。
- `risk_cell`：本次需要关闭的具体风险。
- `evidence_method`：源码、浏览器、截图、运行链路、构建结果或远端回读。
- `result`：通过、发现问题、证据不完整或能力受限。
- `decision/status`：关闭、待修复、待确认或因改动失效。

不要为了记账额外计算文件哈希；已有差异、构建版本或交付文件指纹足以区分状态时，直接复用。

## 复用已有证据

以下条件必须同时成立，才能把后续动作判定为零新增价值并复用已有结果：

1. 验证对象和候选版本相同。
2. 风险问题相同。
3. 证据方法和验收口径相同。
4. 视口、测试数据和交互状态相同。
5. 上次结果完整、可读取且没有能力限制。
6. 中间没有相关修改或外部状态变化，本次也不承担独立复核职责。

任一条件变化，都重新检查受影响范围。没有发现缺陷但关闭了预先声明的高风险项，仍然属于新增价值。

## 子代理分工

| 角色 | 风险重点 | 主要证据 | 写入边界 |
|---|---|---|---|
| 总协调 | 范围、冲突、最终决策 | 任务契约、证据账本 | 统一合并和发布 |
| 源码基线 | 结构、状态、样式来源 | 源码、依赖、数据流 | 默认只读 |
| 浏览器基线 | 真实呈现与交互状态 | 页面、截图、computed style | 默认只读 |
| 状态契约 | 连续操作、保存和恢复 | 状态转换、边界用例 | 默认只读 |
| 实施 | 组件或闭环实现 | 明确文件和组件 | 只写分配范围 |
| 视觉复核 | 布局、主题、长文本和可访问性 | 多状态、多视口页面证据 | 只读验收 |
| 交互回归 | 主链路、失败和恢复 | 真实操作与状态结果 | 只读验收 |
| 工程与交付 | 类型、构建和产物来源 | 检查结果、最终 HTML | 构建产物 |
| 反向审查 | 遗漏、串扰和业务偏差 | 对抗性用例和冲突证据 | 默认只读 |

每个代理派单必须说明：

- 要关闭的风险问题。
- 相比已有工作新增的证据。
- 结果会改变的决策。
- 允许读取和写入的范围。
- 取得什么证据后停止。

同一模块允许多代理并行，但必须负责不同风险格、使用不同证据方法，或承担明确的独立复核责任。不要让多个代理执行相同范围、相同方法和相同验收问题的泛化检查。

## 改动与验收

| 改动类型 | 定向验收 | 最终候选回归 |
|---|---|---|
| 局部文案、间距 | 目标区域、关联点击和可读性 | 本轮页面 |
| 局部组件样式 | 默认、悬停、选中、禁用和目标宽度 | 相关页面 |
| 全局主题 `token`、壳层、菜单 | 全部壳层状态和相邻区域 | 全部壳层 |
| 状态或数据模型 | 状态转换、保存、切换、失败和恢复 | 相关业务链路 |
| 构建配置、依赖 | 类型、lint、构建和资源完整性 | 最终 HTML |
| 发布目标或远端状态 | 本地候选确认 | 发布后远端回读 |

修复产生新状态后，重新执行受影响的定向检查。共享样式、状态核心或跨模块数据发生变化时，扩大回归范围。所有修复结束后，再对同一个最终候选版本执行本轮验收清单的完整回归。

## 必要的独立证据

以下组合验证不同风险，不能因为对象相同而合并：

- 源码检查与浏览器呈现。
- 类型、构建与真实运行。
- 截图与 `computed style`。
- 实施者自测与独立复核。
- 修复前复现与修复后复测。
- 定向验收与最终完整回归。
- 默认、悬停、选中、展开、收起和禁用状态。
- 普通宽度与最小可用宽度。
- 源码工程与打包后的单 HTML。
- 本地验收与发布后远端回读。

## 反馈与任务边界

- 后一项判断依赖前一项真实效果时，保留逐项迭代。
- 反馈彼此独立且方向明确时，可以集中修改和验收。
- 后续问题仍依赖同一证据链时，继续当前任务。
- 目标、来源体系、权限或交付物发生变化时，生成精简交接后新建任务。
- `Token`、工具调用、上下文压缩和代理数量只触发价值复盘，不自动终止任务。

## 发布回读

发布前取得明确授权，并确认发布对象就是通过最终回归的候选版本。发布后从远端重新检查版本、页面加载、关键入口和至少一条主链路。远端回读回答的是发布结果，不能由本地验收代替。
