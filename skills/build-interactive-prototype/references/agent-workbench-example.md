# Agent 工作台的数据与状态案例

仅在原型包含资产库、测试对话、冻结快照和外部触发时读取；不要把案例的业务名和字段强加给其他产品。

连续输入的处理先看当前业务约定。只有材料明确要求归入同一次请求时，才追加到同一个 `Request`，并在中断旧生成后基于完整输入重新生成；其他产品可以采用排队、独立请求或其他已确认方式，不套用本案例。

### 多个模块怎样共用数据

当资产管理、创建流程、列表和工作台共享业务对象时，先定义哪些数据共同引用、哪些在创建时保存副本：

- 为学员、场景快照、知识库配置和外部触发资产分配稳定 ID；使用 ID 建立引用，名称只用于展示，旧数据兼容时才按名称回退。
- 创建测试对话时保存所选资产 ID，并深拷贝场景快照形成 `frozenSnapshot`；从该冻结副本恢复工作台所需的历史、虚拟时间、待办、Memory 和 MCP 数据。
- 让 QT、普通外呼、AI 外呼和加好友配置共用一份资产源；让资产页和工作台从同一来源读取，禁止分别维护常量副本。
- 按测试对话和资产类型记录一次性结果的已用 ID；不要使用名称或单个通用布尔值代替各业务规则。
- 让新建表单、Agent 选项和提示词版本读取同一份知识库配置源；让已有测试对话保留创建时的配置标识和展示信息。
- 只在初始化或显式迁移时对旧数据做一次性回填；不得在每次渲染或进入页面时重复补全并覆盖旧会话字段。
- 删除资产前按稳定 ID 检查旧会话、新会话、已用外部结果和其他引用方；仍被引用时阻止删除并说明位置。未来接入对比测试时，将其加入同一引用校验。
- 分别检查旧会话和新会话：旧会话保持原列表展示并从冻结快照恢复；新会话使用最新资产创建独立快照；来源场景快照变化不改写旧会话，约定为实时读取的外部触发资产继续联动，已用结果不能重复执行。
