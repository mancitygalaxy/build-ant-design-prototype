# 素材来源与许可

本参考库按使用者要求一并归档图片和展示视频，供跨设备学习、比较与评审。文件保持所保存版本的原始字节，不将第三方素材重新声明为本仓原创。

- RonDesignLab 的 15 组作品：每组 README、`来源.json` 与总索引保留作品链接及页面署名；包括 RonDesignLab、Jack R. 等原页面署名。图库中的页尾作者介绍图也原样保留。
- 首轮 8 张精选：与完整图库存在重复，另包含一张视频封面；看图页和媒体清单记录对应原作。
- 浅色参考中的公开来源截图：分别来自 Neka、Stripe Billing、Radix Themes。另有一张用户提供的本地 HTML 示例截图，原实现作者及方式未核实，不等同于 Neka 原作。

第三方图片、视频、人物、标志和相关品牌的权利归各自权利人；本仓 MIT 许可只覆盖可由本仓授权的代码与笔记，不覆盖这些媒体。提供学习副本不等于获得将其用于产品、商用或再次分发的许可，实际采用时遵守原权利人的许可条件。

[媒体清单](媒体清单.json)提供每份文件的相对路径、原作定位、字节数和 SHA-256。外部作品链接需要联网，已归档的媒体无需重新下载即可查看。
