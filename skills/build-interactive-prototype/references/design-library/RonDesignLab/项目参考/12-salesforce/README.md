# Salesforce Opportunities｜单一阶段主卡、青蓝重点和下方数据网格

来源：[Salesforce Opportunities - Deals in progress Mobile App](https://dribbble.com/shots/27771690-Salesforce-Opportunities-Deals-in-progress-Mobile-App)；页面署名：RonDesignLab；查阅日期：2026-10-23。

本页为查阅当日的观察记录；查看图片请使用上方原作链接或项目已有原图。

## 看到的设计

- 浅色页面先给项目标题与更新时间，再给一张青蓝色阶段卡，周期与状态在主卡上直接出现。
- 主卡下方为两列金额与人数等数据，数字显著大于标签；底部悬浮导航用黑色选中圆强调当前区域。
- 阶段卡有细环形装饰和荧光黄点，颜色集中在主卡，其他信息保持较轻表面。

## 可以怎么用

适合移动经营看板、项目详情和进度跟进。一个当前阶段加少量相关指标，比把桌面所有模块缩小到首屏更易形成主次。

## 落地时要调整

浮动导航在图片中靠近底部内容，实际页面必须留安全区和滚动空间；装饰环不能被误认为有精确数据含义。作品使用产品名，不代表已核实官方实现。
