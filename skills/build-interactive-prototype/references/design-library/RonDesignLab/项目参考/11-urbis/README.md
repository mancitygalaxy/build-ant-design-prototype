## 看到的设计

- 卫星地貌占据主体，任务区域有描边和半透明覆盖；选中位置由白色胶囊标题、中心标记和虚线圈共同强调。
- 上方搜索栏采用深绿灰底，底部操作为深色大圆角按钮组，控件都与地图形成前后关系。
- 白色任务标签与深色操作区各自保持形状清晰，细节丰富的地图仍作为背景。

## 可以怎么用

适合巡检、外勤和地点相关任务。重点学习选中对象清楚、常用操作在底部集中。

## 落地时要调整

不能照搬卫星地图的视觉密度到普通任务列表；户外屏幕、遮挡、定位误差与底部触达均需现场验证。
