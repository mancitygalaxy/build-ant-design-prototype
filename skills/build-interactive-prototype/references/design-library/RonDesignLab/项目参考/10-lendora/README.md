# Lendora｜浅色地图、左右信息栏与暖黄到淡紫的详情面

来源：[Lendora - Property Map Management Dashboard](https://dribbble.com/shots/27753253-Lendora-Property-Map-Management-Dashboard)；页面署名：Jack R. for RonDesignLab；查阅日期：2026-10-23。

本页为查阅当日的观察记录；查看图片请使用上方原作链接或项目已有原图。

## 看到的设计

- 左侧市场数据、中部低对比地图、右侧选中房产详情形成三段关系；详情的大金额位于上方，具体属性分组向下展开。
- 地图上的选中点以黄色区域和黑色价格标签突出；其他点维持较轻轮廓，过滤控件直接贴近地图。
- 右侧详情由上部暖黄过渡到下部淡紫，3D 建筑与数值属性并置；颜色变化服务于一个完整详情区域。

## 可以怎么用

适合区域经营、对象分布与详情联动。可复用“概览—位置—选中对象”的空间结构，而不是默认每个工作台都需要地图。
