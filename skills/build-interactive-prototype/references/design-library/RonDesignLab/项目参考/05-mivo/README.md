## 看到的设计

- 白色图表与说明区通过弧线过渡到粉色下半区，边界本身带来节奏，未全部套用同样的矩形卡片。
- 绿、橙、蓝的具象小物放在粉色场景中，荧光黄小标签用于强调；颜色丰富但与物件、标签和背景各自对应。
- 药物列表与趋势界面保留明显的数字、短标签和大面积留白；具象元素主要出现在可辨认的选择对象附近。
