## 换设备后使用

从仓库下载 ZIP 并解压，或克隆仓库；完整保留本目录与各级子目录。安装制作 Skill 时复制完整包，图库和媒体也会随包带过去。

已有 Python 3 时，Mac 可双击 `启动参考库.command`，Windows 可双击 `启动参考库.cmd`。脚本仅在 `127.0.0.1` 开启服务，自动选择空闲端口并打开浏览器；按 Control-C 停止。浏览器不会自动打开时，使用终端显示的地址。

也可在本目录运行 `python3 serve.py`；Windows 使用 `py -3 serve.py`。脚本按自身位置找到资料，工作目录无需固定。没有 Python 3 时，可让当前助手用已有本地 HTTP 服务打开此目录。下载后的图片、视频可离线查看；原作网页需联网。

## 采用与来源

优先使用用户指定参考；缺少指定来源时说明缺口，暂停依赖它的判断。工作区已有更新的 `设计参考/` 时，按项目交接卡核对当前试验版本与认可范围；其他原型、运行记录不随本包分发。

笔记不能代替看图。色彩、字体和材质观察不等于已知原作 CSS、组件或动效；静态展示不证明完整交互与业务效果。具体配色由当前项目决定，整体认可不代表确认全部颜色或页面。

原作署名、链接与文件校验见[媒体清单](媒体清单.json)和各组来源。第三方媒体不适用本仓 MIT 许可，详见[素材来源与许可](素材来源与许可.md)。
