# 界面设计参考索引

整理于 2026-10-23。这里随 Skill 提供研究笔记、复用建议与原始来源链接，供不同设备按任务选用；原作图片、视频和本机原型未随包分发。

| 入口 | 内容 | 如何使用 |
| --- | --- | --- |
| [RonDesignLab](RonDesignLab/README.md) | 15 组作品的逐组观察、来源与适配建议 | 按任务、设备和信息密度选案例，再打开原作实际看图 |
| [设计经验与复用指南](RonDesignLab/设计经验与复用指南.md) | 构图、颜色角色、文字尺度、表面关系、AI 与移动端 | 按需取用，不视为固定视觉规范 |
| [浅色界面研究与试验经验](浅色界面/README.md) | Neka、Stripe、Radix、Carbon 的来源及采用边界 | 区分原作观察、实现候选与实际验证 |

优先使用用户指定的参考。已有工作区若保存 `设计参考/`，先按项目交接卡或资料索引定位原图、当前试验版本与认可范围；这些本机资料不在本包内，也不自动代表其他项目的决定。没有可选本机库时可使用这里的原始链接；用户指定来源无法访问时，说明缺口，暂停依赖它的判断。

笔记不能代替看图。色彩、字体和材质观察不等于已知原作 CSS、组件或动效；静态展示不证明完整交互与业务效果。具体配色始终由当前项目决定，整体认可也不代表确认全部颜色或页面。

本仓只分发整理者撰写的笔记。引用作品、品牌与相关素材的权利归各自权利人；本仓 MIT 许可不授予原作素材权利。制作与发布产品时使用自有或明确可用的素材，保留来源。
